# Nalin Dalal — Portfolio

Personal portfolio and blog built with Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, and MDX. Documenting open-source contributions and side projects, exported as a static site and deployed on Vercel / Netlify.

## Quick start

```bash
bun install
bun run dev
```

`bun` is the package manager of record (`bun.lock` is the committed lockfile). Open `http://localhost:3000`.

No environment variables are required to run the dev server. Optional: `GITHUB_TOKEN` raises the GitHub API rate limit when running `bun run update:prs` — the script works without it.

## Structure

- `app/` — Next.js App Router pages: projects, blogs, resume, services.
- `blogs/` — PR write-up posts as `.md` files with frontmatter, one folder per topic (`blogs/asyncapi/`, `blogs/processing/`). Routed automatically at `/blogs/<topic>/<file>` via the filesystem — no manifest to regenerate.
- `case-study/` — MDX project deep-dives, linked from the `caseStudy` field in `data/projects.json`.
- `data/` — `projects.json` (hand-edited content), `mergedPRs.json` (regenerated by CI every 6 hours via `bun run update:prs`), `user.json` / `repositories.json` (raw GitHub API dumps served verbatim by `app/api/data/route.ts`).
- `scripts/updateMergedPRs.js` — fetches merged PRs from the GitHub API.
